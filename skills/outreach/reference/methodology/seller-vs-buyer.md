# 卖方还是买方

**共享件,不是渠道。** 第二跳走到落点站之后、写进表之前的一道判别,各渠道通用。

抓到邮箱不等于这个人会接推广单。落点站是**内容站**(有受众要变现,卖方)还是
**产品站**(自己在买流量,买方),决定这一行是渠道还是潜在客户。实测在 Reddit 一轮里,
拿到邮箱的人有一多半是产品 founder——这是这套方法最大的误报源。

## 三级证据,从硬到软

**一级:行为证据,单条即定案。** 站上有赞助/广告/media kit 页,有招商表单,
首页已经挂着别人的广告位,或者邮箱前缀本身就是招商用途(`advertise@`、`sponsor@`、
`partnerships@`)。这类不是自我宣称,是已经在卖的痕迹。

**二级:站点形态,两边同时打分。** 内容站的标志是 RSS、文章归档、订阅框、跑在 newsletter
平台上;产品站的标志是定价页、免费试用、支付服务商、应用商店徽标。两组分数一起看,
产品分明显高就否掉,别只看内容分。

**三级:平台上的行为节奏。** 反复发不同主题的原创内容是创作者;反复推同一个产品是 founder。
单次爆款几乎总是产品发布。

## 一个必须两段做的坑

赞助类关键词假阳性很高——代码托管平台的赞助按钮、页脚的「我们的赞助商」都会命中。
**关键词命中只能进候选,必须再取一次上下文才能定案。** 粗筛和精判是两步,合成一步就会
把买方当卖方写进表。

## 边界

判别结果是**一列标记加证据来源**,不是过滤器。买方不是脏数据,是另一张名单;
留在表上由人决定,不在流水线里替人丢掉。
