# LinkedIn

**不做。** 这一条是定的,其余待探索。

三个理由,任一条单独成立:

- 没有公开的人物检索,官方 API partner-gated —— **发现这一步根本不存在**。
- 「联系信息」只对一度人脉可见。认证解决的是能不能看到资料页,**不解决能不能看到
  联系方式** —— 所以打通登录也不会让这个渠道变高产。
- 自动化检测最严,封号不可逆,而那是本人的真实职业身份。

本机 Chrome 有 `li_at`(已登录),技术上能走 —— 不走是判断,不是能力问题。
