# 身份与去重

键从主页链接解析。判断只有一个问题:**这个域名是不是这个人独占的?**

- **独占**(个人站、自有域名的 newsletter)—— 域名本身就是键。
- **共享**(视频站、社交站、写作平台、赞助位市场)—— 域名加上路径里那段唯一标识。
- **共享但没有路径段** —— 无键。

哪些域名算共享,是一份配置清单;不在清单上的默认视为独占。解析前先归一化——移动版与 www 前缀、
大小写、结尾斜杠都要抹平,同一个人的不同写法必须算出同一个键。

求不出键的记录丢弃,进运行报告。硬写进表里没有意义:它没有可比的键,下轮照样被当成新的,
只会让表长出无法收敛的行。

## 两道去重

**第一道按键**,发生在抓取之前,挡住已知的人。
**第二道按联系方式**,发生在抓取之后——同一个联系地址出现在两行,就是同一个人的强信号。

第二道白捡,专治一人多主页导致的跨来源重复:一份 newsletter 既挂在赞助位市场又有自有域名时,
两个键不同,但邮箱是同一个。

## 无键的历史行

表里有一批历史记录只有名字、没有主页链接,参与不了前两道去重,只能按名字兜底。

名字匹配不可靠,所以它**只用来标记,不用来丢弃**:名字撞上时照常建行,但状态直接写成已联系,
让人一眼看见。宁可多一行让人判断,不可少一个人。
