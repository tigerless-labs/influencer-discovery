# 设计文档索引

这个 skill 只负责三件事:**打通数据层、记录规范、防重复**。其余都是读写操作。

- [platforms.md](platforms.md) —— 打通:每个平台从哪进、怎么走、联系方式藏在哪一跳。
- [records.md](records.md) —— 记录规范:往表里写什么、运行报告记什么。
- [dedup.md](dedup.md) —— 防重复:两个来源的键、两份清单、路径日志。

## 五阶段

发现 → 求键 → 预筛 → 抓联系方式 → 落表。一条直线,没有回路。

去重发生在两个时点,因为两个键不在同一时刻拿到。**正确性只由落表保证**,预筛是可省的优化,
只为省抓取成本。

## 不变量

- **只追加,不修改。** 创建新行,永不改动任何已存在的格。人爱改哪列改哪列,不会冲突。
- **显示名永不作键。** 人会改名换头像,链接与地址里的标识符不会。
- **宁可留空,不可编造。** 身份能定就写;地址取不到就留空——那是「试过、没找到」。

## 范围

止于拿到联系方式。发信、分层、成交跟踪、点击结算都在外面。

**优先什么、这轮要多少、先跑哪个平台——使用时再定**,不预先写死。设计只保证这些决定
留得下痕迹。
