# Sheet 契约

流水线只写**目标表**——一行一个人,回答「这是谁、怎么够得着」。

联系记录表是**事件表**,一行一次联系。流水线从不联系任何人,所以永不往那里写行;
凭空创造几百次没发生过的联系,语义就是错的。

## 零结构改动

目标表现有的列已经够用:身份、平台、主页链接、联系方式及其形态、状态。流水线只填这几列,
其余留空由人填。**不加列、不加表、不改任何现有列的语义。**

## 只追加

流水线创建新行,永不修改已存在的格。新行的状态是建行时的初值,此后归人。

## 平台列的语义

平台指**人所在的地方**,不是打算用的联系渠道。现有数据这一列混着两种含义,新写入的行不跟随。

## 已知现状

目标表曾被绕开:一段时间里工作直接记在联系记录表上,没有回填,导致相当一部分联系过的人
不在目标表里。补齐是**一次性动作**,不是持续同步。

两表之间没有双向同步,只有人的自然流动:从目标表挑人,联系后记一行。流水线持续往目标表补人,
正是它当初被绕开的原因得到解决——没有东西持续填充它。
