# 分层裁决

层级回答「先联系谁」。它是**规则的产物,不是手感的产物**:同样的输入必须得到同样的层级;
规则改了,要能说清哪些目标因此升降。

分层依据与阈值全在配置里。裁决只有一份实现——排序、筛选、报表共用同一套规则,绝不为某个
用途另写一遍。这是设计不变量。

排序的直觉来自转化率:与本产品主题重合越深、越近期公开表达过相关兴趣的人越靠前。

**生态同行单独成层。** 对他们的目标是建立关系而非推销,话术与成功标准都不同;混进同一层
就会用错话术,一次就把关系用掉。

**付费位单独成层且默认关闭。** 只走明示的赞助位。买赞、买帖、买票、买伪装自来水在任何
层级都被拒绝——这是代码里的护栏,不是文档里的倡议。
