# 流水线

五个阶段,一条直线,没有回路。流水线止于**拿到联系方式**——发信、分层、成交跟踪都不在内。

1. **发现** —— 渠道 adapter 按配置抓候选。见 [data-layer.md](data-layer.md)。
2. **求键** —— 从主页链接解析稳定键。见 [identity.md](identity.md)。
3. **去重** —— 对照目标表现有行,命中即丢弃。
4. **抓联系方式** —— 两跳:平台页到本人站点。
5. **追加** —— 只往目标表追加新行。见 [sheet-contract.md](sheet-contract.md)。

去重排在抓取之前:先筛掉已知的,再花抓取成本。

## 设计不变量

- **只追加,不修改。** 流水线创建新行,永不改动任何已存在的格。人爱改哪列改哪列——不会与流水线
  冲突,因为它从不回头。这一条替代了逐列声明所有权。
- **显示名永不作键。** 人会改名换头像,主页链接里的标识符不会。
- **宁可留空,不可编造。** 身份能定就写;联系方式取不到就留空——留空的含义是「试过、没找到」,
  比猜一个地址安全得多。
