# 已抓产物入库 + 规模下限

两件独立的事,一次做完:早先实验抓过的 Reddit 资料页从没进过流水线;本轮起低于下限的规模
不再进表。

## 1. 设计文档

- `records.md`:**发现可以来自本轮之外** —— 既有产物导入后走同一条判定与记录路径。
- `records.md`:**规模是拒绝项还是排序项,由本轮给不给下限决定**;未核实的规模不算低于下限。

验收:两条都在文档里,且没有把渠道做法写进去。

## 2. 规模下限

闸门多一个下限参数,默认不设。**只有量到的规模才可能低于下限** —— 量不到的照旧不拒绝,
否则拿不到粉丝数的渠道会被整批判死。

验收:量到 800 的被拒、量不到的不受影响、不给下限时行为与现在完全一致。

## 3. Reddit 资料页产物导入

Reddit 的第一跳多一个来源:**已抓好的资料页外链**。只有本人声明的自有域名算自有站,
外链里的平台地址不算。没有外链的人照样入库 —— 抓过就是抓过,不入库下一轮会再抓一遍。

这条来源不需要登录态,不能被取不到 session 拖死。

验收:自有域名进 `own_site`、平台链接不进、坏行跳过、无外链的人仍产出候选、
无 session 时这条来源照常出人。

## 4. 端到端
