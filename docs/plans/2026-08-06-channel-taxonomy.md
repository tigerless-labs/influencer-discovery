# 渠道分类收窄:博主 / 分发站 / 媒体 / 发布社区

## 起因

目标表里混进了没有分发能力的产品站。根因是渠道分类按**地址属不属于个人**切,
而真正该切的是**这个对象能不能帮我们做分发**。

现有三份的错配:

- `website.md` 定位「公司站或产品站」,兼着两个职责:分发站发现 + 所有第二跳落点的解析。
- 多作者媒体(VentureBeat、InfoQ、The New Stack 等)按 `blog.md` 的指引落到 `website.md`,
  但键是公司名,会把一家媒体的几百个作者塌成一行;`website.md` 的职能地址例外还会把
  `editors@` 当成有效联系方式收下。
- 发布社区(DEV.to、Hashnode)无归属,methodology 的 index 里只写着「空着」。

## 决定

**目标是能帮我们做分发的人或站。** 三级,`docs/design/` 定,不随轮次变:

| 级 | 是什么 | 处置 |
|---|---|---|
| 一级 | 博主 / 创作者 —— 有自己的受众 | 主目标,进表 |
| 二级 | 做分发的站 —— 工具推荐站、目录站、榜单站 | 进表 |
| 不联系 | 做自己产品的站 | 只进 log,不进表 |

**媒体只是一份清单,不抓。** 存在的唯一理由是防止把媒体误当博主渠道跑。
不写投稿入口——那属于发信侧,在 repo 范围外。

## 单元

每个单元的验收标准写在前面。

### 0. `CLAUDE.md` 与 `SKILL.md` —— 把目的写清楚

**验收:**两份的第一段都能回答「找谁、为什么、门槛是什么」,不用往下读。

现在两份都只说「把博主找出来」,没说**为谁找**,也没说**门槛**。补两件事:
找的是能帮 Tigerless Labs 推广作品的人;**必须自带受众**——有粉丝、有读者、有订阅者。
做自己产品的人不是目标,他要的是流量,不是给我们分发。

### 1. `docs/design/index.md` —— 目标定义

**验收:**「范围」一节能回答「谁算目标」,且说明这条不是使用时定的旋钮。

加一段三级定义。不写渠道名、不写做法。

### 2. `seller-vs-buyer.md` —— 处置从标记改为闸门

**验收:**「边界」一节不再说「买方留在表上由人决定」。

三级证据体系不动——判别方法仍然有效,只改判别之后怎么处置:
买方不进表,只进 log。这是**不变量变更**,`docs/design/index.md` 的准入两条要能推出它。

### 3. `website.md` —— 收窄为分发站

**验收:**第一句定位是分发站;去重键不再是公司名;文档里没有「从公司站挖出个人」的做法。

- 定位改为:工具推荐站、目录站、榜单站——**产出是分发,不是某个人**。
- 去重键 `(站点名, Website)`。
- 职能地址例外保留但改口径:分发站的投递入口(`submit@`、收录表单)算数。
- **落点解析通则移进 `landing-page-two-hop.md`**:四步判归属、名单页防串味、
  `/team` 与 `security.txt` 那两条。它们是所有渠道共用的第二跳知识,
  按 CLAUDE.md「共同的第二跳只写一次」该住那里。移,不删。

### 4. `blog.md` —— 加发布社区清单

**验收:**读者能判断一个写作平台归 blog 还是归发布社区,且清单里每一条有归属。

发布社区 = 注册就能发、无编辑门槛。清单只写**定位与归属**,
不写命中率——没跑过的数字按写作规约不许进正文。

### 5. 新 `media.md`

**验收:**第一句说明它是清单、裁决为不做;正文没有投稿入口、没有抓取做法。

### 6. 索引与 TODO 清扫

**验收:**`methodology/index.md`、`SKILL.md` 的渠道覆盖、`docs/TODO.md` 三处同步。

- methodology `index.md`:`media.md` 进「裁决为不做」;删掉「未写的:DEV.to」那句。
- `SKILL.md` 的 description 覆盖列表加媒体与发布社区的归属。
- `docs/TODO.md`:媒体作者页当发现源(未承诺)、发布社区各平台未跑通。

## 不做

- 不写投稿/买 sponsor 位的做法。
- 不为产品站单开一份 methodology——不联系就不需要方法。
- 不动 `dedup.md` 的规则:键仍是 `(人, 平台)`,这次改的是谁算目标,不是怎么判重。

## 无测试与端到端

`src/outreach/`、`tests/` 当前为空,本次是纯文档改动。实现到位后,
三级定义要落成进表前的一道判别,届时补测试。
